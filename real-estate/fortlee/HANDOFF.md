## 1. 목표 (Steve의 요구)

부모님 노후 대비로 **뉴저지 포트리 온누리교회 근처**에 **멀티패밀리(2~3가구) 주택**을 사서,
한 세대는 부모님 거주·나머지는 렌트아웃 → **렌트 후 월 순수익 $1,000 이상**을 만든다.

## 2. 하드 요구사항 (Steve 프롬프트 원문 정리)

1. 위치: **뉴저지 온누리교회 = 1449 Anderson Ave, Fort Lee, NJ 07024** 근처, **도보 가능하면 최고**.
2. 가격: **~$1,000,000 (협상 가능)**.
3. 자금: **현금 최대 $750,000**, 나머지는 모기지. (모기지 = 매입가 − $750k)
4. 유형: **멀티패밀리(2가구 이상)**. 한 층 거주 + 한 층(들) 렌트아웃.
5. 부모님 **65세 이상** → **NJ 시니어 재산세 혜택** 활용.
6. **렌트아웃 후 월 순수익 ≥ $1,000** 필수(노후 대비).
7. **년식 중요**, **주변 실제 렌트 시세 확인**, **breakdown + 순수익** 제시.
8. **더 생각할 점**까지 찾아 **시각적으로** 설명.
9. ★**데이터는 반드시 최신**이어야 함 — 이게 가장 큰 페인포인트(팔린 매물이 계속 섞임).

## 3. 검증된 사실 (변하지 않음 — 그대로 사용)

- 교회 1449 Anderson Ave, Anderson Ave Walk Score 86("매우 도보친화").
- **재산세: 실제 연 ~$12,000** (인근 실제 고지서 $11,345~$13,155, 평균 $12,506).
  실효세율 ~1.89% / 공칭 2.607%. **단순 %×매입가($21k)는 과대** — 과세표준이 시세보다 낮음.
- **렌트 (2가구 한 층, 고급타워 아님):** 2BR ≈ **$2,700**, 3BR ≈ **$3,200**
  (2욕실+주차+세탁기면 $3,500+). 근거: 1154 Anderson 한 세대 실제 $3,500 임대.
- **시니어 혜택(65+):** StayNJ(재산세 50%, 최대 $6,500/년) + ANCHOR(~$1,250) +
  Senior Freeze(인상분 동결) = **연 ~$7,750**. **2년차부터 적용**(직전 1년 소유·거주 요건).
  소득한도 $200k(StayNJ). **렌트 수입이 소득에 잡혀** Senior Freeze 한도에 영향 가능 → 회계사.
- **맨션세:** 2025-07-10부터 **셀러 부담**(과거엔 매수자). **$1M 미만 면제**, 초과 시 누진.
- **렌트컨트롤(Fort Lee Ch.324):** 2가구 규제 대상, 연 인상 ≤5%(시니어 세입자 3.5%).
  **거주적합증(COC, Ch.182)** 세입자 교체마다 필요($100).
- **시장 규모(2026 중반):** 포트리 멀티패밀리 ~6건(중간 $1.25M) · 팰팍 ~7건($859k–$2.8M) ·
  클리프사이드 ~6–12건($770k–$1.8M, 중간 $1.14M).
  **도보권 진짜 2가구는 현재 거의 0** (1154 매각·1612 매각·244 Lincoln 계약중).

## 4. 재무 모델 / 매수 기준 (월 $1,000+ 달성 조건)

현금 $750k 고정 → **모기지가 작을수록 순수익↑.** 목표를 넘기는 3가지 경로:

| 전략 | 설명 | 예상 순수익/월 |
|---|---|---|
| **A. 리걸 3가구** | 두 세대 렌트 → 모기지 커도 렌트가 이김 | **+$1,200 ~ +$3,600** |
| **B. ~$70만 2가구 전액현금** | 모기지 $0 | **≈ +$1,700** |
| **C. ≤$88만 2가구 + 모기지 ≤$13만** | 시니어 혜택 적용 | **+$1,000 ~ +$1,400** |
| (참고) 풀 예산 $1M · 모기지 $250k | 모기지 상환이 순수익 잠식 | ≈ +$430 (미달) |

**추천:** 클리프사이드파크 1순위(교회 ~1.5mi·차5분, 한인 밀집, 멀티패밀리 재고·저가 매물 많음)
또는 **리걸 3가구**. 도보권(포트리)만 고집하면 재고가 없어 대기 필요.

모델 가정: 30년 고정 ~6.5% · 보험 $2,600/년 · 수도하수 $1,200/년 · 수선충당 $3,800/년(노후주택↑) · 공실 5%.
계산기: 라이브 리포트에 매입가·현금·렌트·세금·시니어 토글 → 실시간 순수익.

## 5. ★데이터 문제 & 해결책 (다음 에이전트 필독)

- **웹 스니펫(Zillow/Redfin/구글 캐시)은 status 필드가 없고 캐시가 낡음** → 팔린/계약중이 "판매중"으로
  반복 노출됨. **스니펫으로 매물 status를 신뢰하지 말 것.**
- **개발 컨테이너(Claude Code 클라우드)는 모든 부동산 API 호스트를 정책 차단**(RentCast·Redfin·Bridge
  전부 403). 따라서 **라이브 조회는 외부(무제한 네트워크)에서 실행해야 함.**
- **구축해 둔 해결책:** GitHub Actions 워크플로우 `.github/workflows/rentcast-fortlee.yml` —
  **GitHub 러너(무제한 네트워크)에서 RentCast 실행**, 결과 JSON을 실행 로그에 출력.
  리포 시크릿 `RENTCAST_API_KEY`만 등록하면 동작(검증 완료: 시크릿 없을 때만 실패).
- **툴킷** `real-estate/fortlee/tools/`:
  - `rentcast_listings.py` — RentCast(status·DOM·MLS#, Active만 → 매각/계약중 자동 제외). **권장.**
  - `bridge_listings.py` — Bridge/Zillow RESO MLS. **데이터셋(MLS) 승인 필요**(`--datasets`로 확인).
  - `fetch_listings.py` — Redfin(무료·키 없음·Active만).
  - `redfin_mcp.py` — 로컬 Claude용 MCP(rentcast/bridge/redfin 도구).
  - `DATA_SOURCES.md` — 소스 전체 비교.

**소스 우선순위:** RentCast(무료 50/월·라이선스 불필요·status O) ▶ Bridge/Zillow(MLS 원본, 데이터셋 승인
필요) ▶ NJMLS via 에이전트(SimplyRETS/Bridge, 라이선스 필요, 완벽 실시간).

## 6. 키/자격증명 (★문서에 값 미포함 — 별도 안전 전달)

- Steve 보유: **RentCast API 키**, **Bridge Interactive(Zillow Group) 키**(Client ID/Secret, Server/Browser
  Token). **새 에이전트에는 시크릿/환경변수로 전달**하고 이 문서엔 넣지 말 것.

  NJMLS 없으면 매물 0건 → RentCast로 대체.
