# SAT 11월 7일 D-27 — 등록 마감 10월 23일, 한인 수험생·부모 지금 당장 확인해야 할 5가지

**2026년 11월 7일 SAT까지 27일 남았습니다.**

10월은 한인 가정에서 대입 준비가 가장 바쁜 달입니다. ED/EA 마감(11월 1일), FAFSA 접수, 그리고 이번 달 안에 결정해야 하는 SAT 등록까지. 11월 SAT를 놓치면 다음 기회는 12월 5일이지만, 그때는 Regular Decision 마감에 바짝 붙어 있어 숨쉴 틈이 없습니다.

지금 확인하고 결정해야 할 5가지를 정리했습니다.

---

## 핵심 일정 요약

| 날짜 | 항목 |
|---|---|
| **10월 23일** | SAT 11월 등록 마감 (D-12) |
| **10월 27일** | 추가 등록 마감 + 시험장 변경 마감 (수수료 추가) |
| **11월 1일** | 대부분 ED/EA 원서 마감 |
| **11월 7일 (토)** | SAT 시험일 |
| **11월 20일** | 점수 공개 |
| **12월 5일** | 다음 SAT 시험일 |
| **12월 18일** | 12월 SAT 점수 공개 |

---

## 1. ED/EA 지원자라면: 11월 점수는 RD·ED II용

많은 한인 가정이 혼동하는 부분입니다.

**11월 7일 시험 → 11월 20일 점수 공개**

대부분의 대학 Early Decision / Early Action 마감은 **11월 1일**입니다. 즉 **11월 7일 SAT 점수는 ED/EA 지원에 쓸 수 없습니다**.

### 내 상황에 맞는 전략

| 상황 | 11월 SAT 응시 필요 여부 |
|---|---|
| ED/EA 지원 예정이고 현재 점수로 충분 | ❌ 11월 응시 불필요 |
| ED/EA 지원 예정이지만 점수 부족 | ✅ 응시 후 ED II / RD 지원에 활용 |
| RD 지원 예정 (마감 1월) | ✅ 적극 권장 — 12월보다 여유 있음 |
| 점수 이미 만족스럽고 스트레스 관리 중 | ❌ 불필요 |

---

## 2. 지금 등록해야 하는 이유 — 시험장 조기 마감

뉴저지·뉴욕 한인 밀집 지역 시험 센터는 매년 빠르게 마감됩니다.

### NJ/NY 지역 인기 시험장 (일반 참고 — 잔여석 실시간 변동)

- **뉴저지 버겐 카운티**: 포트리 고교, 팰리세이즈파크 고교, 리지필드파크 고교 등
- **뉴욕 플러싱·베이사이드**: 플러싱 지역 고교, 베이사이드 고교 등
- **뉴욕 시내**: 스타이브산트 고교, 브루클린 텍 등

> **지금 확인 방법:** collegeboard.org → Register for the SAT → 11월 7일 선택 → 우편번호 입력 → 반경 내 남은 시험장 확인

일반 등록 마감이 **10월 23일(12일 후)**이므로 지금 확인하지 않으면 원하는 시험장을 놓칠 수 있습니다.

## 3. 디지털 SAT 2026 — 한인 수험생이 꼭 알아야 할 5가지

College Board는 2024년부터 모든 SAT를 **디지털 방식(Digital SAT)**으로 전환했습니다. 종이 시험을 경험한 부모 세대와 형제자매와는 완전히 다릅니다.

### 디지털 SAT 핵심 구조

| 항목 | 내용 |
|---|---|
| 응시 앱 | **Bluebook** (College Board 공식, 노트북/태블릿에 사전 설치 필수) |
| 점수 범위 | 400~1,600점 (읽기·쓰기 200~800 + 수학 200~800) |
| 시험 시간 | **약 2시간 14분** (이전 3시간에서 단축) |
| 섹션 구조 | 읽기·쓰기(RW) 2모듈 + 수학 2모듈 |
| 적응형(Adaptive) | 1모듈 성적 → 2모듈 난이도 자동 조정 |
| 계산기 | **전 수학 구간 허용** (Desmos 내장) |
| 연습 시험 | Khan Academy + College Board Bluebook 앱에서 무료 제공 |

### 중요: 시험 전날까지 반드시 확인

1. ✅ **Bluebook 앱 설치·업데이트** 완료 여부 (구형 iPad/노트북 호환 확인)
2. ✅ **대여 기기 사용 시** 학교/도서관 사전 승인 확인
3. ✅ **Accommodation(장애·특수편의)** 신청 완료 여부 (이미 마감됐을 가능성)
4. ✅ **신분증** 준비 (여권 또는 사진 있는 학생증·운전면허)
5. ✅ **충전기·이어폰 없이** 배터리 100% 충전 후 입장

## 4. 27일 남은 점수 향상 전략

남은 27일을 효과적으로 쓰는 단계별 계획입니다.

### 1주차 (D-27~D-21): 현재 위치 진단

1. **Khan Academy Full Practice Test** 1회 응시 (무료, 실제 환경과 동일)
2. 섹션별 약점 분석 — 읽기·쓰기 vs. 수학 어느 쪽이 취약한가
3. 목표 점수와 현재 점수 차이 확인

### 2주차 (D-20~D-14): 집중 약점 보완

| 약점 유형 | 추천 접근법 |
|---|---|
| 읽기 속도 부족 | 하루 2개 지문 타이머 연습, 문단 요약 훈련 |
| 어휘·문법 오류 | College Board 공식 어휘 리스트 + 문장 교정 연습 |
| 수학 기초 공식 | Desmos 활용 연습 + 공식 암기 카드 |
| 수학 응용(Word Problem) | 문제를 한국어로 도식화(키워드 번역·그림)한 뒤 Desmos로 풀기 |

### 3주차 (D-13~D-7): 실전 감각 훈련

1. **Full Practice Test 1회** 추가 응시 (타임 어택, Bluebook 앱)
2. 오답 패턴 분석 및 반복 틀리는 유형 집중 정리
3. 시험 당일 동선(시험장 위치, 교통, 소요시간) 사전 답사

### 4주차 (D-6~D-1): 컨디션 관리

1. 새로운 유형 시도하지 않기 — 이미 아는 개념 다지기
2. **수면 7~8시간** 유지
3. D-1(11월 6일 금요일): 가벼운 복습 후 일찍 취침

## 5. 점수 활용 계획 — 발표(11월 20일) 이후 행동

11월 20일 점수 공개 후 시나리오별 행동 가이드입니다.

### 목표 점수 달성 시

- ✅ 지원 대학에 **Score Send** (College Board → 대학 직접 전송, 대당 $13, [College Board 수수료 안내](https://satsuite.collegeboard.org/sat/scores/send-sat-scores))
- ✅ RD 지원 시 점수 포함해 업데이트 에세이 제출 가능한 학교 확인
- ✅ 한국 대학원·교환학생 프로그램 요구 점수 충족 여부 확인

### 목표 점수 미달 시

- ⚠️ **12월 5일 SAT** 추가 응시 고려 (등록 마감 11월 20일 — 점수 공개 당일!)
- ⚠️ 대부분 RD 마감(1월 1~15일)까지 12월 점수(12월 18일 공개) 제출 가능
- ⚠️ **Score Choice**(College Board 정책): 어느 시험 날짜 점수를 각 대학에 보낼지 본인이 선택 가능
- ⚠️ **Superscore**(각 대학 정책): 여러 시험 날짜에서 섹션별 최고점을 합산해 주는 제도 — MIT, Yale, Columbia 등 허용. 학교마다 다르므로 반드시 해당 대학 입학처에서 확인

### 주요 대학 Superscore 정책 현황 (참고용 — 매년 변경 가능, 반드시 대학 홈페이지 재확인)

| 정책 | 대학 예시 |
|---|---|
| Superscore 허용 (섹션별 최고점 합산) | MIT, Yale, Columbia, Penn, Dartmouth, Brown 등 |
| 전체 점수 제출 요구 (Score Choice 불가) | University of California 계열 |
| 정책 불명확 또는 변경 가능 | 학교마다 다름 → 각 대학 Common Data Set 또는 입학처 홈페이지에서 확인 |

## 등록 절차 요약 (지금 바로)

1. **collegeboard.org** 접속 → 로그인(계정 없으면 가입)
2. **Register for the SAT** 클릭 → 11월 7일 선택
3. 우편번호 입력 → 가까운 시험장 선택 (잔여석 확인)
4. 수수료 결제 ($68, 저소득층 Fee Waiver 가능)
5. 등록 확인 이메일 저장
6. 시험 약 1주 전 **Bluebook 앱** 설치 및 연습 시험 1회

> **추가 등록(10월 27일 마감)은 $30 추가 수수료 발생**
