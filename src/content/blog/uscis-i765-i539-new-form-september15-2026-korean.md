# I-765·I-539 구버전 9월 15일 전면 거부 — 유예기간 없음, OPT·체류연장·비자변경 신청자 즉시 확인

**지금 OPT, H-4 EAD, 체류 연장, 비자 신분 변경을 준비 중이라면 이 글부터 읽으세요.**

2026년 9월 15일, USCIS는 두 가지 핵심 이민 양식을 동시에 교체합니다:

- **Form I-765** (Application for Employment Authorization, 취업허가 신청서)
- **Form I-539** (Application to Extend/Change Nonimmigrant Status, 체류 연장·신분 변경 신청서)

9월 15일 이후 구버전 양식을 제출하면 **유예기간 없이 즉시 거부(rejection)** 됩니다. 수수료도 환불되지 않습니다. 취업허가증(EAD) 발급이 지연되거나 체류 신분이 위험해질 수 있습니다.

> ⚠️ **이 글은 법률 자문이 아닙니다.** 본인 케이스는 이민 전문 변호사와 확인하세요.

|---|---|---|

| 교체되는 구버전 | 08/21/25판 | 08/28/24판 |
| 새 양식 버전 | **09/15/26판** | **09/15/26판** |
| 유예기간 | **없음** | **없음** |
| 구버전 허용 마지막 날 | 9월 15일 이전 우편소인 또는 전자 제출 | 9월 15일 이전 우편소인 또는 전자 제출 |
| 구버전 제출 결과 | 즉시 거부, 수수료 몰수 | 즉시 거부, 수수료 몰수 |

## 나는 해당되나 — 신청서 유형별 확인

### I-765 구버전이 거부되는 케이스

1. **F-1 학생 — OPT(Optional Practical Training) 신청**
   - 졸업 후 또는 졸업 예정인 한인 유학생이 EAD를 신청할 때 I-765를 사용합니다
   - 9월 15일 이후에는 반드시 09/15/26판을 사용해야 합니다

2. **STEM OPT 연장 신청**
   - STEM 전공 졸업생이 24개월 OPT 연장을 신청할 때도 I-765가 필요합니다

3. **H-4 EAD — H-1B 배우자 취업허가**
   - H-1B 취업비자 소지자의 배우자(주로 H-4 비자 소지자)가 취업허가를 신청할 때 I-765를 제출합니다
   - 한인 H-1B 취업자 가정에서 배우자가 해당될 수 있습니다

4. **기타 체류 신분 전환 후 EAD 신청**
   - 망명 신청자(Asylum), U·T 비자 소지자, 특정 다른 신분에서 EAD 신청 시 포함됩니다

### I-539 구버전이 거부되는 케이스

1. **F-1·J-1 체류 연장**
   - 학업 기간이 길어져 I-20 또는 DS-2019를 연장받은 경우, 그에 맞춰 체류 기간도 연장 신청 필요 (특히 D/S 폐지 이후)

2. **B-1/B-2 방문 비자 체류 연장**
   - 방문 중인 부모, 가족이 체류 연장을 원하면 I-539가 필요합니다

3. **신분 변경(Change of Status)**
   - 예: B-2 방문 → F-1 학생 신분으로 변경
   - 예: J-1 → H-4 신분 변경

4. **F-2·J-2 동반 가족**
   - F-1·J-1 주 신청자의 동반 배우자·자녀가 별도로 체류 연장 또는 신분 변경 시 I-539 제출

## 왜 유예기간이 없나 — D/S 폐지 최종규칙

이번 양식 교체가 이례적으로 유예기간 없이 시행되는 이유는 **Duration of Status(D/S) 폐지 최종규칙**과 동시에 발효되기 때문입니다.

### D/S란 무엇이었나

지금까지 F-1·J-1 비자 소지자는 입국 시 I-94에 정확한 날짜 대신 **"D/S"** 가 찍혔습니다. 이 표시는 "유효한 학생·교환 신분이 유지되는 동안 체류 가능"을 뜻했으며, 이론상 학업 기간 동안에는 따로 만료일을 추적하지 않아도 됐습니다.

### 새 규칙 — 고정 기간 부여

9월 15일부터 F-1·J-1 비자로 입국하는 학생과 교환 방문자는 **구체적인 체류 만료일(Specific Date)** 이 I-94에 기재됩니다. 이 날짜를 넘기면 체류 신분 위반(Overstay)이 되어 향후 비자 발급·영주권 신청에 불이익이 생깁니다.

이에 따라 I-539(체류 연장·신분 변경)와 I-765(EAD 신청) 양식도 이 새로운 규칙을 반영한 버전으로 교체된 것입니다. USCIS가 유예기간을 두지 않은 이유는 "새 규칙 시행일과 양식 교체일을 일치시켜야 처리 오류를 막을 수 있기 때문"이라고 설명했습니다.

## 9월 15일 기준 — 내 상황별 행동 지침

### 시나리오 A: 9월 14일 이전 제출 예정

**구버전(08/21/25판 I-765 / 08/28/24판 I-539) 사용 가능합니다.**

- 우편 제출: 봉투 소인이 9월 14일 또는 그 이전이어야 합니다. 9월 12일까지 발송 권장
- 전자 제출: 9월 14일 23:59(ET) 이전에 제출 완료해야 합니다
- 서류 패킷에 이미 채워진 양식의 날짜(Edition Date)를 다시 한번 확인하세요

### 시나리오 B: 9월 15일 이후 제출 예정

**반드시 새 양식(09/15/26판)을 사용해야 합니다.**

1. 9월 15일 당일 USCIS.gov/i-765 또는 USCIS.gov/i-539에서 09/15/26판을 다운로드합니다
2. 기존에 작성한 내용을 새 양식에 옮겨 적습니다
3. 이민 변호사나 대리인과 함께 준비 중이라면, 변호사 사무소가 새 양식으로 교체할 일정을 확인합니다
4. 타사 법무 소프트웨어(Docketwise, SimpleCitizen 등)를 쓰는 경우 해당 소프트웨어가 09/15/26판으로 업데이트됐는지 확인 후 사용합니다

### 시나리오 C: 현재 USCIS 처리 대기 중

**이미 접수된 케이스는 영향 없습니다.** USCIS가 양식을 수리한 날(Receipt Date) 기준으로 구버전이 합법적으로 접수됐다면, 처리 중에 새 양식으로 재제출하라는 요청은 없습니다.

## 양식별 주요 변경 내용

### I-765 (취업허가) — 09/15/26판 변경 사항

- **고정 기간 기반 I-94 대응 질문 추가**: 기존 D/S로 입국한 학생과 새 규칙 하에 고정 기간을 부여받은 학생을 구분하는 항목이 신설됩니다
- **체류 기간 증빙 요건 업데이트**: F-1·J-1 신청자의 경우 I-20 또는 DS-2019의 유효 기간과 연동된 체류 증빙 항목이 조정됩니다

### I-539 (체류 연장·신분 변경) — 09/15/26판 변경 사항

- **I-94 만료일 관련 질문 갱신**: D/S 기재 I-94를 보유한 기존 학생과 새 고정 기간 I-94를 보유한 학생이 각각 다른 응답 경로를 따릅니다
- **동반 가족(Derivative) 응답 경로 정비**: F-2·J-2 동반 가족의 체류 증빙 항목이 새 규칙을 반영합니다

## 수수료는 달라지나

이번 양식 교체로 **I-765 또는 I-539 자체 수수료는 변경되지 않습니다.** 기존 수수료가 유지됩니다.

단, 구버전 양식을 잘못 제출해 거부당하면 수수료를 다시 납부해야 합니다. 거부 시 수수료 환불이 없으므로 주의하세요.

- [ ] 현재 작성 중인 I-539 양식 하단 "Edition" 날짜 확인 — 08/28/24판인지 확인

### 9월 15일 이후 제출 예정

- [ ] 9월 15일 USCIS.gov에서 새 양식(09/15/26판) I-765 또는 I-539 다운로드
- [ ] 새 양식에 답변 재작성 (내용은 같아도 양식 자체를 교체)
- [ ] 이민 변호사에게 새 양식 기반 검토 요청

- [ ] 현재 I-94에 "D/S" 기재 여부 확인 (CBP I-94 웹사이트: i94.cbp.dhs.gov)
- [ ] 새 학기 입학·재입국 예정이라면, 9월 15일 이후 입국 시 고정 만료일이 부여됨을 인지
- [ ] 학교 국제학생처(ISSS/OIS)의 9월 신규 공지사항 확인
