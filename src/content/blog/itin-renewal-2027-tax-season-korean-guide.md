# ITIN 만료 확인·갱신 지금 해야 2027년 세금 환급 받는다

**지금 갱신하지 않으면 2027년 4월 세금신고에서 자녀세액공제, 근로소득세액공제를 받지 못할 수 있습니다.**

ITIN(Individual Taxpayer Identification Number·개인납세자 식별번호)은 소셜시큐리티 번호(SSN)가 없는 한인 이민자, 비자 소지자, 미국 비거주 외국인 납세자들이 세금신고에 사용하는 번호입니다. 많은 분들이 ITIN이 이미 만료됐다는 사실을 세금신고 시즌이 되어서야 알게 됩니다.

IRS W-7 처리는 **7~11주**가 소요됩니다. 지금(10월) 신청하면 2027년 1월에 갱신 완료 → 4월 세금신고 마감에 여유 있게 맞출 수 있습니다.

## 핵심 요약

| 항목 | 내용 |
|---|---|
| ITIN 갱신 신청서 | **IRS Form W-7** |
| 처리 기간 | **7~11주** (우편 발송 기준) |
| 지금 신청 시 완료 예상 | 2026년 12~2027년 1월 |
| 세금신고 마감 | 2027년 4월 15일 |
| 갱신 수수료 | **무료** |
| 만료 시 영향 | 주요 세액공제 보류, 환급 지연 |

## 내 ITIN이 만료됐는지 확인하는 방법

### ✅ 확인 방법 1: 중간 두 자리 확인

ITIN은 9XX-XX-XXXX 형식입니다. 가운데 두 자리를 확인하세요.

| 중간 두 자리 범위 | 만료 여부 |
|---|---|
| 70~82 | ❌ 만료 (2018년 12월 31일) |
| 83~87 | ❌ 만료 (2020년 12월 31일) |
| 88 | ❌ 만료 (2021년 12월 31일) |
| 90~92, 94~99 | ❌ 만료 (2021년 12월 31일, 2013년 이전 발급분) |
| 위 범위 외 | 아래 2번 방법으로 추가 확인 |

### ✅ 확인 방법 2: 3년 미사용 확인

중간 두 자리가 만료 범위에 없더라도, **2022년, 2023년, 2024년 세금신고(Form 1040 또는 1040-NR)에 한 번도 사용하지 않았다면 2025년 12월 31일에 자동 만료**됩니다.

예를 들어, 미국에 있는 자녀를 부양가족으로 올린 부모님이 한국에 계시면서 세금신고를 하지 않았다면, 그 부모님의 ITIN이 만료됐을 가능성이 높습니다.

### ✅ 확인 방법 3: IRS에 직접 확인

```
IRS 전화: 1-800-829-1040
IRS Taxpayer Assistance Center(TAC): irs.gov/help/contact-your-local-irs-office에서 가까운 곳 찾기
NJ 주요 TAC: Newark · Cherry Hill · Eatontown
NY 주요 TAC: Manhattan (290 Broadway) · Brooklyn · Jamaica · Staten Island
```

## ITIN 갱신이 필요한 대표적인 케이스

### 케이스 1: H-4·L-2·F-2 비자 배우자
H-1B, L-1B, F-1 비자 소지 배우자를 따라온 종속 비자 소지자입니다. 소셜시큐리티 번호가 없어서 ITIN으로 세금신고를 해왔습니다. 지난 3년간 소득이 없어 신고를 안 했다면 ITIN이 만료됐을 수 있습니다.

### 케이스 2: 미국 자녀를 부양가족으로 올리는 해외 거주 한국 부모
한국에 거주하면서 미국 시민권 또는 영주권 자녀를 부양가족으로 올리기 위해 ITIN을 받은 경우입니다.

### 케이스 3: 비거주 외국인(Non-Resident Alien) 납세자
미국 부동산 임대소득, 로열티, 배당 소득에 대해 세금신고를 해야 하는 한국 거주 납세자입니다.

### 케이스 4: 영주권 취득 전 세금 납부 목적
영주권 신청 중 체류 기간이 길어 세금 납부 이력이 필요한 분들이 ITIN을 받은 경우입니다.

## W-7 갱신 신청 절차 — 단계별 가이드

### 1단계: W-7 양식 다운로드

IRS.gov에서 최신 버전 W-7 다운로드:
- 주소: irs.gov/forms-pubs/about-form-w-7
- 이유 코드(Reason Code): 대부분 한인 이민자는 **Code b** (Nonresident/Resident Alien) 또는 **Code d** (Dependent of U.S. citizen/resident) 선택

### 2단계: 신분 증명 서류 준비

신분 확인 서류가 없으면 갱신이 거부됩니다. 다음 중 하나가 필요합니다.

| 서류 | 신원 확인 | 외국인 신분 확인 |
|---|---|---|
| **여권** (원본 또는 공증 복사본) | ✅ | ✅ |
| 한국 주민등록증 + 미국 비자 | ✅ | ✅ (두 서류 함께) |
| 한국 국가신분증 + 의료보험증 | 일부 경우 인정 | — |

> ⚠️ **여권 원본 우편 발송이 걱정된다면**: IRS Certifying Acceptance Agent(CAA)를 찾으세요. CAA는 원본을 확인 후 공증 복사본만 IRS에 제출합니다. 많은 한인 CPA나 세무사가 CAA 자격을 보유하고 있습니다.

### 3단계: 우편 발송 또는 TAC 직접 방문

- **우편**: Internal Revenue Service, ITIN Operation, P.O. Box 149342, Austin, TX 78714-9342
- **TAC 방문**: 사전 예약 후 신분 서류 지참 방문 → 원본 확인 후 즉시 반환
- **CAA 대리 제출**: CAA가 서류를 수령, 검토 후 IRS에 직접 제출

### 4단계: 처리 현황 확인

- 우편 발송 후 7주 이내 확인 없으면: 1-800-829-1040 전화
- IRS TAC 예약 후 방문 시 빠르면 현장에서 처리 가능

## 자녀·배우자 ITIN도 한 번에 갱신하세요

세금신고서에 기재된 모든 가족의 ITIN이 유효해야 공제를 받을 수 있습니다.

### 가족 구성원별 확인 체크리스트

- [ ] 신청자 본인 ITIN 유효 여부 확인
- [ ] 배우자 ITIN 유효 여부 확인 (공동신고 시)
- [ ] 부양 자녀 ITIN 유효 여부 확인 (미국 시민권 자녀는 SSN 사용)
- [ ] 해외 부모님 ITIN 유효 여부 확인 (부양가족 공제 신청 시)

가족 W-7은 하나의 봉투에 동봉해 한 번에 보낼 수 있습니다. 각자 별도 W-7을 작성하되, 대표 납세자의 Form 1040에 첨부하거나 "Certificate of Foreign Status" 포함 후 발송합니다.

## ITIN 갱신 vs. 신규 발급

| 구분 | 갱신 | 신규 발급 |
|---|---|---|
| 해당 상황 | 기존 ITIN 만료 | ITIN이 처음인 경우 |
| W-7 체크박스 | "Renew an Existing ITIN" | "Apply for a New ITIN" |
| 처리 기간 | 동일 (7~11주) | 동일 (7~11주) |
| 필요 서류 | 동일 | 동일 |

## 10월~11월 지금 신청해야 하는 이유

| 신청 시점 | 예상 완료 | 2027년 4월 세금신고 |
|---|---|---|
| **10월 초** (지금) | 12월~2027년 1월 | ✅ 여유롭게 준비 가능 |
| 11월 말 | 2027년 2~3월 | ⚠️ 빠듯함 |
| 2027년 1월 이후 | 3~4월 이후 | ❌ 마감 전 완료 불확실 |
| 2027년 4월 세금신고와 동시 | 처리 중 지연 | ❌ 환급 수개월 보류 |

세금신고 시즌(1~4월)에는 TAC 예약이 수주 전 마감되고 CAA도 바빠집니다. 10~11월 미리 처리하는 것이 유리합니다.
