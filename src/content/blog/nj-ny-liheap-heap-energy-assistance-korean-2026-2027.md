# NJ 에너지 지원금 이미 접수 중·NY 11월 2일 오픈 — 한인 가정 LIHEAP·HEAP 완전 신청 가이드 (2026-2027)

겨울이 다가오면서 전기·가스 요금이 크게 오를 시기입니다. 뉴저지와 뉴욕에 거주하는 저소득·중저소득 한인 가정은 **연방·주 에너지 지원 프로그램(LIHEAP/HEAP)** 을 통해 공과금 부담을 줄일 수 있습니다.

중요: 뉴저지 LIHEAP는 **이미 10월 1일부터 접수 중**이며, 예산 소진 시 조기 마감됩니다. 뉴욕 HEAP 정규 혜택은 **11월 2일 오픈 예정**입니다. 지금이 신청 적기입니다.

> ⚠️ 이 글은 정보 제공 목적이며 최신 소득 기준·혜택 금액은 공식 기관에서 확인하세요.

---

## 핵심 요약: NJ vs NY 에너지 지원 비교

| 항목 | 뉴저지 (NJ) | 뉴욕 (NY) |
|---|---|---|
| **프로그램명** | LIHEAP + USF | HEAP |
| **현재 접수 상태** | ✅ **이미 접수 중** (10월 1일~) | ⏳ 11월 2일 오픈 예정 |
| **정규 혜택 마감** | 2027년 6월 30일 (예산 소진 시 조기 마감) | 예산 소진 시까지 |
| **소득 기준** | 주 중위소득의 60% 이하 | 주 중위소득의 60% 이하 |
| **월 1인 소득 기준** | $4,167 이하 | 약 $3,563 이하 |
| **혜택** | 월 $20~$200 공과금 크레딧 (USF) + 난방비 보조 | 가구당 최대 $996 (정규) |
| **온라인 신청** | energyassistance.nj.gov | mybenefits.ny.gov (NYC: ACCESS HRA) |
| **문의 전화** | 1-800-510-3102 | 각 카운티 사회서비스 사무소 |

## 뉴저지 LIHEAP+USF — 지금 바로 신청하세요

### NJ 소득 기준 (2026-2027 시즌)

소득 기준은 주 중위소득의 60%입니다. PSE&G 및 NJ DCA가 고지한 **월 총소득** 기준은 다음과 같습니다.

| 가구 규모 | 월 총소득 기준 | 연간 기준 |
|---|---|---|
| 1인 | $4,167 이하 | 약 $50,004 |
| 2인 | $5,449 이하 | 약 $65,388 |
| 3인 | $6,732 이하 | 약 $80,784 |
| 4인 | $8,014 이하 | 약 $96,168 |
| 5인 이상 | 가구원 1인 추가 시 약 $1,283 추가 | — |

> **출처**: [NJ PSE&G 2026 Program Assistance Income Guidelines](https://nj.pseg.com) / [NJ DCA LIHEAP FY2027 Detailed Model Plan](https://nj.gov/dca/dhcr/)

맞벌이 한인 가정도 4인 가구 기준 연소득 $96,168 이하라면 자격 가능성이 있습니다. 저소득 식당·네일샵·서비스업 종사자 가정은 특히 꼭 확인하세요.

### NJ 혜택 내용

뉴저지 에너지 지원은 두 가지가 결합됩니다.

**1. LIHEAP 난방비 직접 지원**
- 연방 프로그램으로 전기·가스·석유 등 난방비를 직접 보조
- 난방 장비 수리·교체 지원도 포함 (2026년 10월 1일부터 접수 중)

**2. USF (Universal Service Fund) 월정 크레딧**
- 월 $20~$200의 공과금 크레딧을 전기·가스 청구서에 직접 반영
- 별도 신청 없이 LIHEAP 신청과 동일 서류로 동시 접수
- **매년 재신청** 필요 (한 번 받았다고 자동 갱신 아님)

**3. Fresh Start 미납 요금 탕감**
- 미납 잔액이 $60 이상인 경우 자동으로 신청 대상 검토
- 5년에 한 번 미납 요금 탕감 기회 제공

### NJ 신청 방법 (단계별)

1. **온라인**: [energyassistance.nj.gov](https://energyassistance.nj.gov) 또는 [dcaid.dca.nj.gov](https://dcaid.dca.nj.gov)에서 직접 신청
2. **전화**: 1-800-510-3102로 문의 후 가까운 인증 기관 안내 받기
3. **우편/방문**: 60세 이상, 장애인 가구는 우편 신청 또는 가정 방문 신청 가능
4. **서류 업로드**: 신분증, 소득 서류, 유틸리티 청구서를 온라인으로 제출

> ⚠️ **선착순 마감**: 예산이 소진되면 접수가 조기 종료됩니다. 12월 이전에 신청하는 것을 강력히 권장합니다.

## 뉴욕 HEAP — 11월 2일 오픈 D-16

| 혜택 유형 | 오픈 날짜 | 비고 |
|---|---|---|
| 난방 장비 수리·교체 | ✅ 2026년 10월 1일 (이미 개시) | 먼저 신청 가능 |
| **정규 HEAP (Regular HEAP)** | **2026년 11월 2일** | D-16 — 예산 소진 시 조기 마감 |

*정규 날짜는 OTDA 공식 발표로 확정 전 변동 가능. 11월 초 ny.gov 확인 권장.*

### NY 소득 기준 (2026-2027 추정)

뉴욕도 주 중위소득의 약 60% 이하가 기준입니다.

| 가구 규모 | 월 총소득 기준 (추정) |
|---|---|
| 1인 | 약 $3,563 이하 |
| 2인 | 약 $4,653 이하 |
| 3인 | 약 $5,743 이하 |
| 4인 | 약 $6,833 이하 |

> 위 수치는 참고치입니다. 공식 OTDA 발표 자료를 기준으로 하세요.

### NY 신청 방법

- **뉴욕시**: [ACCESS HRA](https://www.nyc.gov/accesshra) 또는 가까운 HRA 사무소
- **뉴욕주 전역**: [mybenefits.ny.gov](https://mybenefits.ny.gov) 온라인 신청
- **우편/방문**: 거주 카운티 사회서비스 사무소

**뉴욕시 한인 커뮤니티 집중 지역**:
- 퀸즈 플러싱 (Flushing): Queens HEAP 사무소
- 퀸즈 베이사이드, 엘름허스트: 각 구역 DSS 사무소
- 맨해튼 코리아타운: Manhattan HEAP 사무소

## 이민 신분별 자격 체크포인트

> ⚠️ 이민 신분에 따라 자격이 다릅니다. 반드시 본인 상황을 기관에 먼저 확인하세요.

| 이민 신분 | LIHEAP/HEAP 자격 |
|---|---|
| 시민권자 | ✅ 자격 있음 |
| 영주권자 (그린카드) | ✅ 자격 있음 |
| 망명 허가자 / 난민 | ✅ 자격 있음 |
| TPS 보유자 | ✅ 자격 있음 (연방 규정상 '적격 외국인') |
| H-1B / L-1 / E-2 비자 | ❌ 연방 LIHEAP 일반적으로 해당 없음 (비이민 비자는 PRWORA '적격 외국인' 미해당). 주 별도 프로그램은 기관 확인 |
| F-1 / J-1 학생·교환 비자 | ❌ 연방 LIHEAP 해당 없음. 주 별도 프로그램 기관 확인 |
| 서류 미비 (Undocumented) | ❌ 연방 LIHEAP 해당 없음 (주 프로그램은 별도 확인) |

## 서류 준비 체크리스트

지금 바로 준비하세요:

- [ ] 정부 발급 신분증 (운전면허증, 여권, 영주권 카드)
- [ ] 모든 가구원의 SSN 또는 ITIN
- [ ] 최근 30일 급여명세서 또는 고용주 소득 확인서
- [ ] 자영업자: 최근 세금 신고서 또는 수입·지출 내역서
- [ ] SSI/SSDI/사회보장 수령 확인서 (해당자)
- [ ] 최근 전기 또는 가스 청구서 (에너지 공급사 계좌번호 포함)
- [ ] 임대차 계약서 또는 공과금 포함 임대 영수증 (세입자)

## 자주 묻는 추가 질문

**Q. 작년에 받았는데 올해도 다시 신청해야 하나요?**
네. LIHEAP/HEAP와 USF는 매 시즌 재신청이 필요합니다. 자동 갱신되지 않습니다.

**Q. 난방을 전기로 하는 경우도 지원받나요?**
네. NJ USF는 소득 기준을 충족하면 전기 요금의 4% 이상 지출 시 지원합니다. LIHEAP도 전기 난방 가구를 포함합니다.

**Q. 집주인이 공과금을 내는 임대 가구인 경우는?**
공과금이 임대료에 포함된 경우, 임대료 영수증과 집주인 확인서를 제출해 간접 지원을 받을 수 있는지 확인하세요.
