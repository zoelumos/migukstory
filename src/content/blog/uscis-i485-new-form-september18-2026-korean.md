# I-485 구버전 9월 18일 자동 반려 — 영주권 신청 예정자 즉시 확인 5가지

**9월 18일까지 I-485를 제출하지 않을 예정이라면 이 글을 먼저 읽어야 합니다.**

2026년 9월 18일, 미국 이민서비스국(USCIS)이 영주권(그린카드) 조정 신청 양식 **I-485를 전면 교체**합니다. 이날 이후 구버전(01/20/25판) 양식을 제출하면 **유예기간 없이 즉시 반려(rejection)**됩니다. 수수료 환불도 없습니다.

> ⚠️ **이 글은 법률 자문이 아닙니다.** 구체적인 케이스는 이민 전문 변호사와 확인하세요.

현재 영주권 신청을 준비 중인 한인이라면 — H-1B 취업비자 소지자, 가족초청 이민 대상자, 난민·망명자 — 지금 당장 확인해야 할 체크리스트와 새 양식의 핵심 변경사항을 정리합니다.

| 동시 시행 규정 | 퍼블릭 차지 기반 입국 불허 최종 규칙 (9월 18일 발효) |

## 왜 지금 바뀌나 — 배경 3분 이해

9월 18일은 **퍼블릭 차지(Public Charge) 최종 규칙** 발효일과 동일합니다. 트럼프 행정부는 영주권 심사에서 공적 지원 수혜 이력을 더 광범위하게 반영하는 새 규정을 9월 18일부터 시행하며, USCIS는 이에 맞춰 I-485 양식을 개정했습니다.

구체적으로 퍼블릭 차지 섹션에서 기존에 두 개로 나뉘어 있던 질문을 하나로 통합하고, 공적 지원을 받은 경우 **혜택 종류·수혜 기간·금액·사유**를 명시하도록 했습니다.

이 규정 자체에 대한 자세한 내용은 [퍼블릭 차지 9월 18일 강화 — 한인 영주권 신청자 점검표](/blog/uscis-public-charge-rule-september-2026-korean-guide)를 참고하세요. 이 글은 **양식 교체에 따른 실무 대응**에 집중합니다.

## 구버전 vs 새 버전 — 무엇이 달라졌나

### 퍼블릭 차지 섹션 변경

**기존 01/20/25판 (2개 질문 분리):**
- 질문 A: "현금 지원 프로그램을 받은 적이 있습니까?"
- 질문 B: "장기 시설 보호를 받은 적이 있습니까?"

**새 09/18/26판 (1개 통합 질문 + 세부 공개):**
- 질문: "수단심사(Means-Tested) 공적 혜택을 받은 적이 있습니까?"
- **예(Yes)** 답변 시 추가 기재: 혜택 이름 / 수혜 시작·종료일 / 수령 금액 / 수혜 사유

수단심사 공적 혜택에는 메디케이드(ACA 확장 포함), SNAP(식품보조), 주택 바우처(Section 8), SSI(보충소득보장) 등이 포함됩니다.

### 기타 변경

USCIS는 퍼블릭 차지 섹션 외에도 기존 중복 질문 일부를 정리하고 양식 용어를 최신 정책 언어에 맞게 업데이트했습니다.

## 내 상황별 행동 지침

### 1단계: 제출 시점이 9월 18일 이전인가, 이후인가?

**9월 17일(소인 기준) 이전 제출 조건:**
- 구버전(01/20/25판) 사용 가능
- 현재 준비 중인 서류 패킷 그대로 사용

**9월 18일 이후 제출 조건:**
- 반드시 새 버전(09/18/26판) 사용
- 9월 18일 USCIS.gov/i-485에서 새 양식 다운로드
- 퍼블릭 차지 섹션을 새 양식에 맞게 재작성 필요

### 2단계: 현재 준비 상태 점검

**지금 서류 패킷을 직접 준비 중인 경우:**

1. 현재 사용 중인 I-485 양식 첫 페이지 오른쪽 하단 또는 하단 푸터에서 **양식 날짜(Edition Date)**를 확인합니다.
2. "01/20/25"이면 구버전입니다.
3. 9월 17일 이전 제출 예정이면 그대로 사용, 9월 18일 이후라면 새 양식으로 교체가 필요합니다.

**이민 변호사 또는 대리인을 통해 준비 중인 경우:**

담당 변호사에게 **"9월 18일 이후 제출 예정인지, 새 양식으로 교체할 계획인지"** 확인하세요. 전문 대리인이 교체를 안내하겠지만, 마감 직전 혼선을 피하기 위해 미리 확인하는 것이 안전합니다.

### 3단계: 우선일(Priority Date) 확인

9월 18일을 전후해 취업 기반 이민(EB 카테고리) 또는 가족 기반 이민의 **우선일이 9월 비자 불레틴 기준으로 현재(Current)인지 확인**하세요. 우선일이 열려 있다면, 어느 양식을 쓸지보다 더 중요한 것은 **적시에 제출하는 것**입니다.

## 이 날짜를 놓치면 어떤 일이 생기나

USCIS의 반려 절차는 다음과 같습니다:

1. **즉시 반려(Rejection)** — 새 양식 발효 후 구버전 접수 시 심사 없이 반려
2. **수수료 환불 없음** — I-485 성인 기준 $1,440 이상 전액 몰수
3. **우선일 보호 상실 위험** — 특정 케이스에서 접수일(Receipt Date) 기준이 사라지면 우선일 혜택 손실 가능
4. **체류 신분 공백 위험** — I-485가 접수돼 있어야 발급되는 고용허가(EAD), 여행허가(AP) 자동 발급이 지연됨

## 퍼블릭 차지 항목 기재 가이드

새 양식에서 공적 혜택 수혜 이력을 기재해야 할 경우 아래 원칙을 따르세요.

| 혜택 | 포함 여부 | 비고 |
|---|---|---|
| 메디케이드 (ACA 확장) | ✅ 포함 | 9월 18일 이후 신청 분 |
| SNAP (식품보조) | ✅ 포함 | |
| SSI (보충소득보장) | ✅ 포함 | |
| Section 8 주택 바우처 | ✅ 포함 | |
| 자녀가 받은 혜택 | ❌ 제외 | 신청자 본인 혜택만 기재 |
| 시민권자·영주권자 자녀 의료 | ❌ 제외 | 부모 케이스에 불산입 |
| 코로나 관련 일회성 지원 (2020~2021) | ❌ 제외 | 퍼블릭 차지 심사 제외 유지 |
| Medicare (65세 이상 의료) | ❌ 제외 | 수단심사 혜택 아님 |

> ⚠️ 퍼블릭 차지 면제 대상(난민·망명자·VAWA·T·U 비자 등)은 공개 의무 자체가 다를 수 있습니다. 이민 변호사 확인 필수.

## 즉시 실천 체크리스트

### 9월 18일 이전 제출 예정인 경우

- [ ] 현재 준비 중인 I-485 양식 날짜 확인 — 01/20/25판인지 확인
- [ ] 동반 가족(Derivative Beneficiary) I-485도 동일 버전으로 준비됐는지 확인
- [ ] 퍼블릭 차지 섹션(Part 5) 답변 검토
- [ ] 우편 제출: 9월 15일까지 발송 목표 (소인 여유)
- [ ] 전자 제출: 9월 17일 23:59(ET) 이전 제출

### 9월 18일 이후 제출 예정인 경우

- [ ] 9월 18일 이후 USCIS.gov/i-485에서 새 양식(09/18/26판) 다운로드
- [ ] 퍼블릭 차지 섹션 새 질문에 맞게 재작성
- [ ] 공적 혜택 수혜 이력 있다면: 혜택 이름·기간·금액·사유 목록 미리 정리
- [ ] 이민 변호사에게 새 양식 기준 퍼블릭 차지 답변 검토 요청
- [ ] 동반 가족도 새 양식으로 교체
