# 2026년 9월 비자불레틴 — 가족이민 F3·F4 우선일 최대 29개월 급진전, 취업이민 정체·FY 마감 경보

미 국무부(Department of State)가 **2026년 8월 22일** 9월 비자불레틴을 발표했습니다. 이번 불레틴은 두 가지 대조적인 메시지를 담고 있습니다. **가족이민은 FY2026 최대 진전**, 취업이민은 전면 정체. 그리고 2026년 9월 30일 회계연도 종료를 앞두고 EB-2·EB-5 소진 경보가 울리고 있습니다.

오랫동안 가족이민을 기다려온 한인 가족에게는 기회의 달입니다. 취업이민을 준비 중인 분들은 FY2026 마지막 기회인 9월 접수를 서둘러야 합니다.

---

## 핵심 요약

| 항목 | 9월 내용 |
|---|---|
| **F3 (기혼 자녀)** | ✅ **2014년 10월 22일** — 29개월 대폭 진전 |
| **F4 (형제자매)** | ✅ **2011년 10월 22일** — 26개월 대폭 진전 |
| **F2B (영주권자의 미혼 성인 자녀)** | ✅ **2019년 8월 22일** — 20개월 진전 |
| **F1 (시민권자의 미혼 성인 자녀)** | ✅ **2020년 1월 22일** — 13개월 진전 |
| **F2A (영주권자의 배우자·미성년 자녀)** | ✅ **2026년 8월 22일** — 사실상 현행 |
| **EB-1 (한국)** | C (현행) — 변동 없음 |
| **EB-2 (한국)** | C (현행) — 변동 없음 |
| **EB-3 (한국, 최종행동일)** | ⚠️ **2024년 9월 1일** — 8월과 동일, 정체 |
| **FY2026 종료** | ⚠️ 2026년 9월 30일 — EB-2·EB-5 소진 위험 |

## 1. 가족이민 우선일 — FY2026 최대 진전

### 최종행동일 (Final Action Dates) — 한국 포함 일반(All Chargeability)

| 카테고리 | 대상 | 9월 최종행동일 | 8월 대비 |
|---|---|---|---|
| **F1** | 시민권자의 미혼 성인 자녀 | 2020년 1월 22일 | **+13개월↑** |
| **F2A** | 영주권자 배우자·미성년 자녀 | 2026년 8월 22일 | +1개월 (사실상 현행) |
| **F2B** | 영주권자 미혼 성인 자녀 | 2019년 8월 22일 | **+20개월↑** |
| **F3** | 시민권자 기혼 자녀 | 2014년 10월 22일 | **+29개월↑** |
| **F4** | 시민권자 성인 형제자매 | 2011년 10월 22일 | **+26개월↑** |

9월 가족이민 우선일은 **FY2026 회계연도 중 가장 큰 진전**을 기록했습니다. 특히 F3(기혼 자녀, +29개월)과 F4(형제자매, +26개월)가 눈에 띕니다.

### 내 가족이민 카테고리별 체크

**F3 — 시민권자의 기혼 자녀**
- 9월 최종행동일: **2014년 10월 22일**
- 내 우선일이 2014년 10월 22일 이전 → ✅ 9월 접수 가능 검토
- 시민권자 부모가 I-130을 2014년 이전에 청원한 경우 해당

**F4 — 시민권자의 형제자매**
- 9월 최종행동일: **2011년 10월 22일**
- 내 우선일이 2011년 10월 22일 이전 → ✅ 9월 접수 가능 검토
- F4는 역사적으로 가장 적체가 심한 카테고리 중 하나. 10년 이상 기다려온 한인 가족에게 진전이 의미 있음

**F2B — 영주권자의 미혼 성인 자녀**
- 9월 최종행동일: **2019년 8월 22일**
- 2019년 이전 우선일 → ✅ 9월 접수 가능 검토

**F2A — 영주권자의 배우자·미성년 자녀**
- 9월 최종행동일: **2026년 8월 22일** (사실상 현행에 근접)
- 최근 I-130 청원자도 접수 자격이 열릴 가능성 있음 → 이민 변호사 즉시 확인 권장

**F1 — 시민권자의 미혼 성인 자녀**
- 9월 최종행동일: **2020년 1월 22일**
- 2020년 이전 우선일 → ✅ 9월 접수 가능 검토

## 2. 취업이민(EB) — 정체, FY2026 소진 경보 발령

### 최종행동일 (Final Action Dates) — 한국 포함 일반(All Chargeability)

| 카테고리 | 9월 일반(한국) | 8월 대비 |
|---|---|---|
| **EB-1** | **C (현행)** | 변동 없음 |
| **EB-2** | **C (현행)** | 변동 없음 |
| **EB-3** | **2024년 9월 1일** | ⚠️ 변동 없음(정체) |
| **EB-5 Unreserved** | **C (현행)** | 변동 없음 |

한국 EB-3 최종행동일은 2024년 9월 1일에서 한 발짝도 움직이지 않았습니다. **EB-3 우선일이 2024년 9월 2일 이후인 신청자는 9월에도 접수 불가**입니다. 변호사와 함께 매월 비자불레틴을 모니터링하세요.

### ⚠️ 긴급 경보 — EB-2·EB-5, FY2026 종료 전 소진 위험

국무부가 9월 비자불레틴에서 다음 카테고리의 **비자 번호 조기 소진** 위험을 공식 경고했습니다:

- **EB-1 인도(India)**: 연간 할당 소진 임박
- **EB-2**: 전체 수요 급증으로 할당 소진 위험
- **EB-5 Unreserved**: 수요 지속으로 소진 가능

**한국 EB-1·EB-2 신청자에게 미치는 영향**: 현재 EB-1·EB-2 한국은 Current(현행)입니다. 그러나 FY2026 남은 비자 번호가 급격히 소모될 경우, 국무부는 2026년 9월 30일 이전에 카테고리를 'Unavailable(접수 불가)'로 전환할 수 있습니다.

1. **이미 I-485 접수 완료자**: 영향 없음. 접수일 기준으로 비자 번호가 확보됩니다.
2. **아직 I-485를 접수하지 않은 EB-1·EB-2 한국 신청자**: 9월 가능한 한 빨리 접수 완료를 목표로 이민 변호사와 즉시 협의하세요. FY2026 마지막 달인 9월 내 접수가 가장 안전합니다.
3. **10월(FY2027) 이후**: 새 회계연도 비자 번호가 리셋되지만, 10월 비자불레틴 발표 전까지 우선일 변동 가능성이 있습니다.

## 3. USCIS 9월 차트 선택 — 반드시 확인 필요

USCIS는 매달 비자불레틴 발표 후 **별도 공시**를 통해 취업이민(EB)과 가족이민(Family) I-485 접수에 어느 차트를 허용할지 발표합니다. **9월 차트 선택은 USCIS 공시 페이지에서 반드시 직접 확인하세요.**

### 차트 선택 확인 절차

1. **단계 1**: [USCIS 비자불레틴인포 페이지](https://www.uscis.gov/visabulletininfo) 방문
2. **단계 2**: "September 2026" 발표 내용에서 EB/Family 각각 허용 차트 확인
3. **단계 3**: 허용된 차트에서 내 카테고리 우선일 확인
4. **단계 4**: 이민 변호사에게 케이스별 접수 시기 최종 검토 요청

> **주의**: USCIS 공시 없이 잘못된 차트로 제출하면 I-485가 거부될 수 있습니다. 반드시 공식 발표를 확인하세요.

## 4. 회계연도 마감(9월 30일) — 지금 행동해야 하는 이유

2026년 9월 30일은 **미국 이민비자 FY2026 회계연도 마지막 날**입니다. 이 날짜가 중요한 이유:

### 타임라인

1. **현재 (2026년 8월 하순)**: 9월 비자불레틴 발표 → 접수 기회 확인
2. **2026년 9월**: FY2026 마지막 달 — 비자 번호 소모 급증
3. **2026년 9월 30일 이전**: 소진 카테고리 'Unavailable' 전환 가능
4. **2026년 10월 1일**: FY2027 개시 → 새 비자 번호 배분 → 10월 비자불레틴 발표

### 조건 → 행동 가이드

- **한국 EB-1 / EB-2 신청자, 서류 준비 완료**: → ✅ 9월 내 I-485 접수 최우선, 지연 금지
- **한국 EB-3, 우선일 2024년 9월 1일 이전**: → ✅ 9월 I-485 접수 가능 — 변호사 즉시 연락
- **한국 EB-3, 우선일 2024년 9월 2일 이후**: → ❌ 9월 접수 불가 — 10월 불레틴 대기
- **F3/F4 우선일 해당 기간 내**: → ✅ 지금 이민 변호사에게 9월 접수 문의
- **F2A 우선일 2026년 8월 22일 이전**: → ✅ 즉각 변호사와 I-485 접수 타이밍 확인

## 9월 행동 체크리스트

- [ ] 내 우선일(Priority Date) 확인 — I-130 또는 I-140 승인 통지서의 우선일
- [ ] 9월 최종행동일 표와 내 우선일 비교 (위 표 참조)
- [ ] USCIS visabulletininfo 페이지에서 9월 차트 선택 공시 확인
- [ ] 가족이민(F3/F4) 해당자 → 이민 변호사에게 I-485 접수 가능 여부 즉시 문의
- [ ] EB-1/EB-2 한국 미접수자 → FY2026 내 접수 완료 목표로 즉시 행동
- [ ] 10월 비자불레틴(2026년 9월 발표 예정) 모니터링 등록
