# DOL, Microsoft·Adobe·Infosys 등 8개 테크기업 PERM 영주권 전면 정지 — H-1B 한인 직장인 즉시 점검 가이드

**2026년 10월 8일, 미국 노동부(DOL)가 8개 주요 테크·IT 기업의 PERM 영주권 신청을 전면 정지했습니다. 이 기업들에서 H-1B로 근무 중인 한인 직장인은 지금 즉시 내 케이스 영향 여부를 확인해야 합니다.**

> ⚠️ **이 글은 법률 자문이 아닙니다.** 상황은 진행 중이며 빠르게 변할 수 있습니다. 개인 케이스는 이민 전문 변호사와 반드시 확인하세요.

## 정지된 8개 기업 목록

DOL이 2026년 10월 8일 기준으로 PERM 처리를 정지한 기업:

1. **Microsoft** (미국 빅테크)
2. **Adobe** (미국 빅테크)
3. **Cognizant** (인도계 IT 서비스)
4. **Infosys** (인도계 IT 서비스)
5. **Tata Consultancy Services (TCS)** (인도계 IT 서비스)
6. **Wipro** (인도계 IT 서비스)
7. **HCL Technologies** (인도계 IT 서비스)
8. **Capgemini** (프랑스계 IT 컨설팅)

DOL은 "다수의 연방 조사가 진행 중"이라고만 밝혔고, 구체적인 혐의 내용은 공개하지 않았습니다. 이번 조치는 연방 수사 중 사기 혐의가 있는 고용주에 대해 PERM을 정지할 수 있도록 허용하는 **20 CFR § 656.31(b)** 규정을 근거로 합니다.

> **참고 전례**: 2026년 5월, DOL은 캘리포니아 소재 소프트웨어 기업 Cloudera를 180일 정지 처분했습니다. DOJ가 허위 채용 절차(U.S. 구직자 배제 목적 스크리닝)로 기소한 사례가 근거였습니다.

## PERM이란? — 5분 핵심 정리

**PERM(Program Electronic Review Management)**은 고용주 스폰서 영주권(EB-2/EB-3)을 신청하기 위한 **노동 인증 단계**입니다. 고용주가 해당 직위에 적합한 미국 시민권자·영주권자를 채용하려고 성실하게 노력했다는 것을 증명하는 과정입니다.

**영주권 취득 경로 순서:**
1. ✅ 고용주의 PERM 신청 → DOL 승인
2. ✅ 고용주의 I-140 청원 → USCIS 승인
3. ⏳ 비자 우선일 도달 대기 (한국 출생자 EB-3: 수년 대기)
4. ✅ I-485(국내) 또는 영사처리(해외) 신청 → 영주권 취득

PERM이 정지되면 **1단계가 막히므로** 아직 PERM을 시작하지 않은 경우 영주권 절차 전체가 멈춥니다.

## 내 케이스는 어디에 해당하나 — 결정 트리

**Q. 위 8개 기업 중 하나에 H-1B로 재직 중인가요?**

- **→ 아니오**: 이번 조치 직접 해당 없음. 그러나 향후 확대 가능성 모니터링 권장.

- **→ 예**: 아래 조건별로 확인하세요.

  **A. 이미 승인된 I-140이 있는 경우**
  - ✅ I-140 자체는 직접 취소 안 됨 (현재까지 보고 기준)
  - ✅ 우선일 유지 가능
  - ⚠️ 회사 정지로 인한 I-140 철회 리스크는 변호사 확인 필수
  - 행동: I-485 제출 타이밍, 직장 이동 시 I-140 유지 여부 변호사 확인

  **B. PERM이 DOL에 보류 중인 경우**
  - ❌ 보류 PERM 처리 중단됨
  - ⚠️ 처리 재개 시점 불명확 (최소 180일 + 연장 가능)
  - 행동: 변호사와 함께 다른 고용주로의 이전 시 I-140 이식(porting) 가능성 검토

  **C. PERM을 아직 시작하지 않은 경우 + H-1B 5~6년차**
  - ❌❌ **가장 위험한 상황**
  - H-1B 최대 체류 기간(6년)이 다가오는데 PERM이 막혔다면, 연장 옵션이 제한됨
  - 행동: 즉시 이민 변호사 상담 — 직장 이동, 다른 비자 신분 전환 옵션 탐색

  **D. PERM을 아직 시작하지 않은 경우 + H-1B 1~4년차**
  - ⚠️ 직접 위기는 아니지만 장기 전략 재검토 필요
  - 정지 기간 중 회사가 스폰서를 계속 제공할 의지가 있는지 확인
  - 행동: 180일 후 정지 해제 여부 모니터링. 해제 안 될 경우 회사 이전 검토

## 긴급 4단계 행동 체크리스트

### 1단계: 내 케이스 현황 즉시 파악 (오늘)

- [ ] 내 H-1B 만료일 확인 (I-94 cbp.dhs.gov에서 확인)
- [ ] PERM 진행 단계 확인: 미시작 / DOL 보류 중 / 승인 완료 후 I-140 진행 중
- [ ] I-140 승인 여부 및 승인 날짜 확인
- [ ] 이민 변호사 연락처 확보

### 2단계: 이민 변호사 긴급 상담 (이번 주 내)

- [ ] 내 PERM 케이스가 정지 대상 기업에 포함되는지 공식 확인
- [ ] 기 제출 PERM 케이스 상태 정지 여부 DOL FLAG 확인 요청
- [ ] 회사 HR/이민 법무팀에 연락 — 회사 차원의 대응 전략 확인

### 3단계: 시나리오별 플랜 B 준비 (2주 내)

- [ ] 타 고용주로 이전 시 I-140 이식(AC21 porting) 가능 여부 확인
- [ ] 다른 비자 신분 전환 옵션 검토: O-1, EB-1A(탁월한 능력), EB-1B(탁월한 연구자)
- [ ] 배우자 비자 신분 또는 배우자 고용주 스폰서 가능성 검토
- [ ] 해외 귀국 또는 제3국 옵션: 현 단계에서 거의 필요 없으나 최악 시나리오 검토

### 4단계: 지속적 모니터링

- [ ] DOL 공식 발표 및 연방관보(Federal Register) 공고 모니터링
- [ ] 소속 회사 이민 법무팀 정기 업데이트 구독
- [ ] 정지 해제 또는 연장 여부 주 단위 확인

## 이번 조치의 배경과 의미

### 트럼프 행정부의 H-1B·PERM 규제 강화 흐름

이번 조치는 갑자기 나온 것이 아닙니다. 트럼프 행정부는 2025년 이후 H-1B와 PERM 사용에 대한 규제를 지속적으로 강화해왔습니다:

| 시점 | 조치 |
|---|---|
| 2026년 5월 | Cloudera PERM 180일 정지 (선례) |
| 2026년 H.R.1 이후 | H-1B 수수료 인상 (스폰서당 약 $10만 수준) |
| 2026년 8월 | USCIS, RFE 없이 즉시 거부 가능 확대 |
| 2026년 9월 | PERM 광고 요건 강화 |
| **2026년 10월 8일** | **8개 주요 테크기업 PERM 전면 정지** |

### VP Vance의 경고 — 더 많은 기업에 확대 가능

백악관 브리핑에서 JD Vance 부통령은 이번 정지 조치가 "다수의 다른 테크기업에도 적용될 수 있다"고 언급했습니다. 인도계 IT 서비스 기업들의 H-1B 프로그램 대규모 활용을 정치적으로 문제 삼는 기류가 지속되고 있습니다.

## 한인 직장인에게 미치는 실질적 영향

한인 IT 직장인이 가장 많이 재직하는 회사들이 포함돼 있습니다. 특히 다음 상황에 해당한다면 지금 즉시 행동이 필요합니다:

**⚠️ 즉시 행동 필요한 그룹:**
- Microsoft, Adobe, Cognizant, Infosys, TCS, Wipro, HCL, Capgemini 재직 H-1B 취업자
- H-1B 5년차 이상이면서 아직 I-140 미승인
- PERM이 DOL에 보류 중인 케이스

**모니터링 필요한 그룹:**
- 위 기업 외 대형 테크사에 재직 중이나 PERM을 진행하지 않은 H-1B 취업자
- IT 서비스 업체(컨설팅, 아웃소싱)에 H-1B로 재직 중인 분
