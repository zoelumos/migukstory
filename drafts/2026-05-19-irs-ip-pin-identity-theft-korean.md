# 세금 신분도용 막는 IRS IP PIN, 한인 납세자 활용법

세금 관련 신분도용은 누군가가 내 사회보장번호(SSN)나 개인납세자번호(ITIN)를 도용해 가짜 세금보고서를 먼저 제출하고 환급금을 가로채는 범죄입니다. 이를 막기 위해 IRS가 운영하는 장치가 신분보호 PIN, 곧 IP PIN입니다. IRS에 따르면 IP PIN은 타인이 본인의 SSN이나 ITIN으로 세금보고를 하지 못하게 막아 주는 6자리 번호이며, 이 번호는 본인과 IRS만 알게 됩니다.

자격은 넓습니다. SSN이나 ITIN이 있고 본인 신원을 확인할 수 있는 사람은 누구나 등록할 수 있고, 부모나 보호자는 부양가족 몫의 IP PIN도 신청할 수 있습니다. ITIN으로 세금보고를 하는 한인도 발급 대상에 포함된다는 점이 중요합니다. 발급 방법은 세 가지입니다. 가장 빠른 방법은 IRS.gov 온라인 계정에서 직접 발급받는 것입니다. 온라인 인증이 어려운 경우, 조정총소득(AGI)이 개인 8만4,000달러·부부 합산 16만8,000달러 이하라면 Form 15227을 제출할 수 있으며, IRS가 전화로 신원을 확인한 뒤 4~6주 안에 우편으로 PIN을 보냅니다. 또는 납세자지원센터(TAC)를 방문해 신원 확인을 거치면 약 3주 안에 우편으로 받습니다.

IP PIN은 한 해 단위로 쓰는 번호입니다. 한 달력연도 동안만 유효하며, 매년 새 번호가 생성됩니다. 온라인으로 등록한 사람은 우편 통지서가 따로 오지 않으므로 매년 온라인 계정에서 새 번호를 직접 확인해야 합니다. 세금보고 시에는 세무 소프트웨어가 요청할 때 6자리 번호를 입력하면 되고, 전자보고든 종이보고든 번호가 틀리거나 빠지면 보고서가 거부되거나 처리가 지연됩니다. 번호를 잊었다면 Form 15227을 다시 내지 말고 IRS의 "Retrieve your IP PIN" 안내를 따르면 됩니다.

한인 커뮤니티 관점에서 IP PIN은 두 가지 의미가 있습니다. 첫째, 보이스피싱과 가짜 환급 사기가 한인, 특히 시니어를 표적으로 삼는 상황에서 IP PIN은 환급금 가로채기를 막는 실질적 방어막이 됩니다. 의무가 아니어도 미리 발급받아 두는 "선제적 조치"로 활용할 수 있습니다. 둘째, 발급 과정 자체를 악용한 사기에 유의해야 합니다. IRS는 "IRS는 절대 당신의 IP PIN을 묻지 않는다"고 못 박았습니다. 전화·이메일·문자로 IP PIN을 요구하면 그것은 사기입니다. 발급과 분실 복구는 반드시 IRS 공식 사이트를 통해서만 진행하시기 바랍니다.

## 핵심 요약

- IP PIN은 타인이 내 SSN·ITIN으로 가짜 세금보고를 하지 못하게 막는 6자리 번호로, 본인과 IRS만 압니다.
- SSN 또는 ITIN이 있고 신원 확인이 가능한 사람은 누구나 신청할 수 있으며, 가장 빠른 방법은 IRS.gov 온라인 계정 발급입니다.
- IP PIN은 1년 단위로 유효하고 매년 새 번호가 생성되며, 세금보고 시 번호가 틀리면 보고서가 거부될 수 있습니다.
- IRS는 절대 IP PIN을 묻지 않으므로, 전화·이메일·문자로 IP PIN을 요구하면 사기로 의심해야 합니다.
