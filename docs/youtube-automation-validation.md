## 3. "무조건 수익화" 관점의 냉정한 현실

- **97%가 수익화 실패**(Frameloop 2026), 3%만 성공. 자동화=쉬운 돈이 아님.
- 2026-07-15 YPP 개정: "repetitious" → **"inauthentic content"**. demonetize 대상 =
  "기사 스크랩 → AI TTS → 스톡/AI 이미지 → 템플릿 슬라이드쇼 → 원문 그대로 읽기".
- **AI 아바타로 금융·법률·의료 다루기 = 수익화 금지** → 우리 니치(이민·세금·건강)에서
  HeyGen류 아바타 툴은 **원천 실격**.
- 통과하는 채널의 공통점: **오리지널 가치·사람의 창작 판단·실제 리서치·독자 포맷**.

→ 결론: 우리 니치에서 살아남는 길은 **오리지널 기사 기반 자체 파이프라인 + 사람 검수**.
   시중 SaaS(AutoShorts/FlowShorts/InVideo/Faceless.so)는 "템플릿 슬롭"이라 대량운영 시
   고위험. Verticals조차 "generic AI b-roll"은 슬롭 리스크 — 우리의 **기사 표/단계
   슬라이드가 오히려 더 안전**(오리지널 시각자료).

## 4. 이번 세션에서 실제로 채택·테스트한 것

Verticals의 검증된 아이디어 중 **수익화에 가장 직결되는 것을 우리 파이프라인에 이식하고
실측 테스트**함:

- **`scripts/youtube/compliance.py`** — Verticals `finance.yaml`의 `forbidden_phrases`
  패턴을 한국어 이민/세금/건강/경제 맥락으로 구현한 **수익화 컴플라이언스 게이트**.
  - 금지 표현(무조건 승인·보장·확정 환급·탈세·무조건 완치 등) 탐지 → 치명 위반 시 빌드 중단.
  - 민감 주제(이민/세금/건강) **전문가 상담 고지 누락** 경고.
  - **원문 verbatim 낭독 위험**(비진정성) 탐지.
  - `make_video.py`에 `①b` 단계로 통합 — 매 빌드 자동 실행.
  - **테스트 결과**: 실제 USCIS 스크립트 ✅통과 / 위반 문구 주입 시 ❌차단(exit 1).
- CTA 나레이션에 민감주제 **자동 고지문구** 추가(위 경고 해소, 클린 통과 확인).
